# Notebooks ,A notebook is an online interface for writing, storing, and running code.Notebook content either appears in a code cell or markdown cell.
# Code cells ,Code cells are meant for writing and running code. A notebook provides a mechanism for running these code cells. Often, this is a play button located within the cell. When you run the code, its output appears after the code. 
# Markdown cells ,Markdown cells are meant for describing the code. They allow you to format text in the markdown language. Markdown language is used for formatting plain text in text editors and code editors.
